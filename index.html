About This Application

This genomic data browser provides interactive access to curated genetic information including:

  • Gene symbols and associated panels
  • Inheritance patterns
  • Penetrance data

Features

  • Real-time column filtering
  • Responsive design
  • Client-side search capabilities
  • Multi-column sorting

Data is loaded from a JSON source and rendered client-side using DataTables.
